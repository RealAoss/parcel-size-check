# Parcel Size Check

Compare a parcel with user-entered carrier length and girth limits.

Open `index.html` in a modern browser. Edit the sample inputs to update the result, then print or download it. Processing stays in the tab.

## Example

Side A (cm) = 40, Side B (cm) = 30, Side C (cm) = 20, Length plus girth limit (cm) = 150. The first result is 140.
